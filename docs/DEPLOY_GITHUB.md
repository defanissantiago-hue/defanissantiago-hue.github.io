# Deploy en GitHub Pages

1. Hacé backup del repo actual.
2. Borrá el contenido de `defanissantiago-hue.github.io` que pertenecía al proyecto anterior.
3. Copiá todos los archivos y carpetas de este paquete a la raíz del repo.
4. Commit: `Scorpion Workouts initial release`.
5. Push a `main`.
6. GitHub > Settings > Pages > Deploy from a branch > main / root.
7. Esperá el deploy y visitá `https://defanissantiago-hue.github.io/`.

No subas claves privadas ni service_role.
